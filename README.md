## 安装方式
### 方式一：直接在线体验（最简单）
1. 把本文件夹放到任意支持 HTTPS 的静态托管（如 GitHub Pages / Vercel / 自有服务器）。
2. 手机浏览器打开 index.html 网址 → 点「分享 / 添加到主屏幕」即可生成 App 图标。

### 方式二：本机起一个服务后手机访问
```bash
cd hk-tv-app
python3 -m http.server 8080
```
手机与电脑同一 WiFi，浏览器访问 `http://电脑内网IP:8080` → 添加到主屏幕。

### iOS / iPadOS
Safari 打开页面 → 底部「分享」→「添加到主屏幕」。原生支持 HLS，无需插件。

### Android
Chrome 打开页面 → 右上菜单「安装应用」/「添加到主屏幕」。

## 自动更新源（新增）
应用会在启动时（以及点「↻ 更新源」按钮时）自动拉取一份在线源清单 `channels.json`，用它**覆盖本地内置源**。这样源地址要更新时，只需替换这一个 JSON 文件，不必重新下载整个 App：
- **自托管（推荐）**：把 `hk-tv-app` 文件夹放到你自己的静态空间后，App 会读取同目录的 `./channels.json`（同源请求，无跨域限制）。你更新该文件、刷新页面即生效。
- **纯内置兜底**：若拉取失败（无网络 / 跨域被拦），应用自动回退到内置的 21 个频道源，不影响使用。
- 最近一次成功拉取的源清单会缓存在本地，断网时也能用上次的结果。

> 说明：当前线上站点未开放跨域（CORS），因此离线包若部署在**非同源**的服务器，直接拉取线上版 `channels.json` 会被浏览器拦截——此时请用「自托管同目录清单」方式（把最新 `channels.json` 放同目录），或依赖内置源。若要我更新线上源，我改发布后你刷新**线上版**链接即为最新。

## 频道源清单格式（channels.json）
```json
[
  { "name":"频道名", "sub":"副标题", "icon":"图标URL或相对路径",
    "kw":["搜索关键词"], "url":"默认源.m3u8", "pool":["备用源1.m3u8","备用源2.m3u8"] }
]
```
icon 支持外链或同目录相对路径（如 `icon-goldrama.png`）；pool 为自动重搜时逐个尝试的备用源。

## 新增功能
- **搜索框**：顶部输入框按频道名称实时过滤（如输入「翡翠」「HOY」「RTHK」）。
- **收藏（☆）**：每个频道右侧星标可收藏，点「☆ 收藏」按钮只看收藏列表；收藏状态本地保存。
- **受限频道备用源池**：HOY 三台、港台 31–35 已内置多个备用源（RTHK 的 akamaihd 老 CDN、`rthk.hk` 官方 feed、HOY 社区中转等），自动逐个尝试。
- **新增 ViuTV**：iptv-org 列表未收录的主流香港免费台（社区源，可能不稳定）。

## 源失效自动重搜（核心特性）
当一个直播源失效（黑屏 / 报错 / 缓冲卡死）时，应用会**自动自愈**：
1. 先尝试本地缓存与内置备用源；
2. 再联网抓取公开源列表 `https://iptv-org.github.io/iptv/countries/hk.m3u`（该列表开放 CORS），按频道关键词（如 Jade / Golden / RTHK TV 31）自动筛选候选源并逐个尝试；
3. 找到可用源后缓存下来，下次直接秒开；全部失败才提示改用官方 App。
手动点「🔄 重搜」可随时强制重新搜索。

## 部署到 GitHub Pages（永久链接，推荐）

仓库已初始化好（main 分支），在你**能访问 GitHub 的电脑**上执行：

```bash
cd hk-tv-live                         # 进入仓库目录
git remote add origin https://github.com/<你的用户名>/hk-tv-live.git
git branch -M main
git push -u origin main
```

推送后在 GitHub 仓库 **Settings → Pages → Build and deployment → Source 选 Deploy from a branch → 选 `main` / `root` → Save**。
约 1 分钟后访问：`https://<你的用户名>.github.io/hk-tv-live/`

> GitHub Pages 默认开放 CORS（`access-control-allow-origin: *`），因此应用里的「↻ 更新源」拉取同目录 `channels.json` 完全可用。
> 以后要增删频道或换源，只需改仓库里的 `channels.json` 重新 push，所有用户刷新即更新；若把仓库协作者加上助手，他也能直接帮你推更新。
